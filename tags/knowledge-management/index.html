LLM Wiki: 지식을 누적하는 AI

RAG가 채우지 못하는 부분 AI를 통해 정보를 얻을 때 주로 사용되는 방법은 RAG(Retrieval-Augmented Generation)이다. 원문을 청크로 나눠 벡터로 저장하고, 질의마다 유사 청크를 검색해 AI에 넘기는 구조다. 작동은 하지만 사용하다 보면 구조적 한계가 드러난다. 여러 문서에 걸친 관계 추론이 어렵고, 매 질의마다 원문에서 다시 시작한다. LLM Wiki — Andrej Karpathy Karpathy의 원본 아이디어와 커뮤니티 구현 사례들 GitHub Gist https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f Andrej Karpathy가 제안한 LLM Wiki는 이 방향을 뒤집는다.

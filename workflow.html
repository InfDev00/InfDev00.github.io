Phase 1 — 초안 생성
사용자 /new-post <섹션> <주제>
예: /new-post unity Unity 잡 시스템 완전 정복
AI 입력 파싱 + 파일 생성
1
섹션·주제 분리, 영문 kebab-case 슬러그 생성
2
hugo new content/<섹션>/<slug>/index.md 실행 → Hugo 아키타입 기반 프론트매터 자동 생성
📄 index.md ← 생성됨 (draft: true)
AI 웹 검색 — 정보 수집
주제 관련 핵심 개념, 최신 정보, 사실 관계를 웹 검색으로 수집.
수집한 정보를 초안의 사실 근거로 활용.
AI 초안 작성
📋 write-style-guide.md 구조 규칙 + 🧠 writing-voice.md 내용 패턴
1
핵심 인용구 > 한 줄 요약 · 섹션 흐름: 왜 → 무엇 → 어떻게
2
평어체, 코드 블록 언어 명시, linkcard / problem-card 숏코드 활용
3
writing-voice.md — 제거 패턴은 처음부터 포함 안 함, 추가 패턴·관점·어조 반영
AI 자동 검토 · 수정
검토 기준 (review 스킬 내장)
① 내용에 거짓·오류 없는지  ② 웹 검색 기반 사실 확인  ③ 중복 내용 없는지
✅ 통과
사본 저장 단계로 바로 이동
⚠️ 경고 / ❌ 위반
해당 항목을 파일에 직접 수정 후 사본 저장
파일 AI 원본 사본 저장
AI가 작성·수정한 최종 초안을 그대로 복사 저장.
📄 index.md → 복사 → 🔒 <slug>.orig.md
/deploy 시 사용자 편집 내용 비교에 사용
Phase 2 — 사용자 수정
사용자 파일 직접 편집
1
📄 index.md 열어 내용 확인·수정 (추가·삭제·관점 변경)
2
프론트매터 draft: true → draft: false 변경
사용자 /deploy "커밋 메시지"
커밋 메시지 생략 시 deploy.sh 내부의 시간 기반 메시지 사용
Phase 3 — 학습 + 배포
AI .orig.md 탐색
find content -name "*.orig.md" 실행
파일 없으면 학습 단계 생략 → 배포로 바로 이동
AI diff 분석 — 내용 패턴 학습
🔒 slug.orig.md vs 📄 index.md 비교 후 분류
변경 유형 반영 대상 섹션
내용 삭제 (AI 과잉 설명·불필요) ✅ AI 초안에서 일관되게 제거하는 내용
내용 추가 (개인 경험·의견·맥락) ✅ AI 초안에 일관되게 추가하는 내용
관점·주제 강조 변경 ✅ 주제·관점 패턴
분위기·어조 변경 ✅ 분위기·어조 패턴
문체·표현 수정 제외 write-style-guide.md 영역
구조·흐름 변경 제외 write-style-guide.md 영역
사실 오류 수정 제외 일회성 수정, 패턴 아님
파일 writing-voice.md 업데이트
기존 패턴과 중복이면 생략, 반복 확인되면 기존 항목 보강.
학습 파일 구조
AI가 제거하는 내용 AI가 추가하는 내용 주제·관점 패턴 분위기·어조 패턴
자동화 deploy.sh 실행
1
🔒 *.orig.md 삭제 (학습 완료)
2
git add · commit · push → main 브랜치
3
GitHub Actions 트리거 → Hugo Extended 빌드 → gh-pages 배포
✅ gh-pages 배포 완료 📖 writing-voice.md 갱신 🗑 .orig.md 삭제
